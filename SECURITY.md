# Security

## Модель угроз (кратко)

Метрика — **локальное** desktop-приложение. Основной актив — файл SQLite на диске пользователя и доступ к окнам приложения на этом ПК.

| Риск | Как закрывается / граница |
| --- | --- |
| Утечка через «облако» | Ежедневный режим не требует аккаунта и сервера |
| Произвольный код из UI | Preload-мост, без полного Node в renderer |
| Порча данных | Экспорт БД; автостраховка перед импортом |
| Сеть | Открытые порты локальных API (если включены) — только на вашей машине и под вашим контролем |

## Чего приложение не делает

- Не является сертифицированным средством ЭДО / УКЭП.
- Не гарантирует защиту диска: шифрование тома / BitLocker — зона ОС.
- Не заменяет политики доступа в домене Windows.

## Отчёты об уязвимостях

Если нашли проблему безопасности в коде:

1. Не публикуйте эксплойт в открытый issue сразу.  
2. Напишите maintainer’у через GitHub Security Advisory репозитория или контакт профиля [krwg](https://github.com/krwg).  
3. Опишите версию, шаги воспроизведения и влияние.

## Данные

Путь БД Windows: `%APPDATA%\metrika\metrika.db`.  
Храните резервные копии отдельно от рабочего диска при критичном учёте.
