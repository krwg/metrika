# Roadmap — Метрика 0.x

Публичный ориентир. Детали реализации живут в issues и коде.

## Сейчас (0.5 «Домашняя»)

- Стабильный локальный склад: каталог, ячейки, сканер, ревизия, сборка
- Бэкапы SQLite, CSV-импорт, этикетки
- Аналитика ABC и план пополнения
- Расширенный локальный контур (организации / CRM / внутренний ЭДО) — без обещания облака

## Ближайшее

- Полировка установщика и обновлений
- Устойчивость COM-сканера и профилей устройств
- Упрощение онбординга «пустой склад → первая приёмка за 5 минут»
- Документация и скриншоты под реальные сценарии мастерской

## Позже (по запросу)

- Опциональный серверный контур для клиентского портала с другого устройства
- Более гибкие печатные формы
- Импорт/экспорт обменов с внешними системами (честные адаптеры, без «магического 1С-всего»)

## Не цели 0.x

- Облачный SaaS как обязательный режим
- Подмена оператора ЭДО / УКЭП
- Переписывание ядра на другой UI-фреймворк без продуктовой нужды
