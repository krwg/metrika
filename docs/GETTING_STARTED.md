# Getting started — Метрика

## Требования

- Windows 10/11
- [Node.js](https://nodejs.org/) **20+** (LTS)
- npm (идёт с Node)
- для сканера — COM-порт (USB-HID-сканеры в режиме клавиатуры тоже работают через поле ввода)

## Установка из исходников

```powershell
git clone https://github.com/krwg/metrika.git
cd metrika
npm install
npm run rebuild
```

`rebuild` нужен для native-модулей (`better-sqlite3`, `serialport`) под Electron.

## Режим разработки

```powershell
npm run dev
```

Поднимаются Vite (UI), компиляция `src/main` и окно Electron.

## Первичная настройка склада

1. Откройте **Хранение** и создайте склад.  
2. Добавьте подсклады и ячейки (желательно со штрихкодами адресов).  
3. В **Категориях** задайте цвета — они видны на карте и в каталоге.  
4. В **Товарах** создайте карточки или импортируйте CSV (см. [USER_GUIDE](USER_GUIDE.md)).  
5. В **Настройках** укажите COM-порт и скорость сканера, если используете serial-сканер.

## Где лежат данные

| Что | Путь |
| --- | --- |
| База приложения | `%APPDATA%\metrika\metrika.db` |
| Резервные копии при импорте | рядом с данными приложения, папка `backups` |

Перед экспериментами сделайте экспорт БД из **Настроек**.

## Сборка релиза

```powershell
npm run dist:win
```

Готовый установщик появится в `release/` (локально; каталог не коммитится).

## Тесты ядра (опционально)

```powershell
npm run test:all
```

Скрипты самопроверки CRM / MI API / ТСД поверх SQLite (`scripts/*-e2e-selftest.mjs`).
