# Contributing

Спасибо за интерес к Метрике.

## Процесс

1. Fork / ветка от `main`.  
2. `npm install && npm run rebuild && npm run dev`.  
3. Для затронутого контура — соответствующий `npm run test:*`.  
4. Pull Request с кратким «зачем» и способом проверки.

## Стиль

- TypeScript, без `any` без причины.
- UI-изменения — в духе существующих тем (см. `App.css`).
- Не коммитьте `dist/`, `release/`, `node_modules/`, логи, локальные `.db`.
- Секреты, персональные базы и внутренние заметки (`listtodo`, audit dumps) в PR не нужны.

## Область правок

Предпочтительны: баги склада/сканера, UX онбординга, тесты, документация.  
Крупные архитектурные сдвиги лучше сначала обсудить в issue.

## Лицензия

Отправляя изменения, вы соглашаетесь распространять их на условиях [GPL-3.0](LICENSE).
